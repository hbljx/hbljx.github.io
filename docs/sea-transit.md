# 海上交通

大地图朝南显示，与参考图一致：**图左是海底隧道，图右是海上地铁，中间是海上观景大桥**。

## 地铁

- 家园站在小屋西侧海岸；山脚站通过步行平台接到大桥的山脚广场。
- 靠近站台按 **E**，或点击右上角互动按钮。女主会走到站台一起候车。
- 三节车厢的地铁按线路往返运行。进站停稳、开门后，两人一起上车，到目的站停稳后按 E 下车。
- 候车时按 **E / Esc** 可取消。车已开动时，按退出会预约下一站下车；车辆停站时可以直接下车。

## 公交

- 大桥两侧设有 **家园站、海桥观景站、山脚站**，公交在左右车道循环往返。
- 走到相应方向的站牌旁，按 **E** 开始双人候车。
- 桥中站有往山脚、回家两个方向；两个终点站均可乘车前往另一端。
- 与地铁一样，行驶途中退出会等到站再下车，不会把角色放到海里。

## 海底隧道

- 从车库开车到小屋东岸，沿岸边道路来到隧道入口（地图左下）。
- **W/S** 前进、倒车，**A/D** 转向，**空格** 刹车；手机使用面板方向按钮。
- 驶进入口后，可按 **T** 或点“隧道领航”，沿弧形道路开到另一端。方向键或刹车可随时接管。
- 隧道下潜到约海平面以下 15 米，通过另一端坡道接入山脚广场；支持返回家园。
- 女主沿用现有双人出游机制上车。隧道边缘有碰撞限制，停车后可按 **E** 在安全位置下车。

## 山脚换乘区

地铁站位于西侧独立站台，公交两向候车区分设大桥两侧，海底隧道出口移至东侧。站台通过步行连接道相连，中央大桥与登山入口保留通行空间。公交站与隧道出口间距约 24 米，两个方向公交候车点相距 25 米。

隧道全线使用连续半圆玻璃顶，海面在隧道内部裁切，玻璃外保留海水、珊瑚、鱼群和海龟。公交、地铁均配有透明侧窗、挡风玻璃、滑动玻璃车门及观景天窗。

公交与地铁站台设有透明玻璃雨棚、背侧挡风玻璃、浅色金属框架和木色座椅。地铁站保留中央入口与贯通步行通道，所有站台的上车侧保持开敞。海上轨道增加连续道床、密排轨枕、双色护栏和导向灯带。

## 本地验证

先运行 `npm run serve`，再在 `github.io` 目录执行：

```sh
npm run check
npm run check:transit
```

交通检查覆盖桌面和手机尺寸的双人地铁往返、公交往返与桥中站、行驶中请求下车、取消候车、隧道双向驾驶、护栏碰撞和安全下车。截图和检查报告保存在 `tools/.check/`。
